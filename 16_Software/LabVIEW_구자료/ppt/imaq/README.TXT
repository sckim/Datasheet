This CD-ROM accompanies the LabVIEW Machine Vision and Image Processing 
Course manual.  Please install the following directories and files into 
the locations indicated:

Exercise:  This directory contains the VI library called lvimaqex.llb
and a directory of images.  These items are used for the course exercises.  
Move the contents of Exercise into the C:\Exercises\LV_Image directory.

Slides:  This directory contains the slides used in the course.  Move this 
directory into the C:\Slides\LV_Image directory on your computer.

Solution:  This directory contains the VI library called lvimqsol.llb and 
contains the solutions to all the exercises done in the course.  Move the 
contents of Solution into a separate C:\Solutions\LV_Image directory on 
your computer.
