To install the LabVIEW Basics-II Course software files, 
copy the two self-extracting files on this disk to a 
temporary folder on your hard drive.  Double-click on 
LVB2SW.exe to extract the course software.  Then you 
can manually move the course software files to the
follwing locations:

LVBas2.llb   to  ..\labview\user.lib
Basics2.llb  to  ..\labview
Scope.fp     to  ..\labview
Scope.dll    to  ..\labview
Panel.bmp    to  ..\labview
LV-HiQ.HiQ   to  ..\labview

where .. is the complete path to your LabVIEW directory.

If you would like to install the solutions to the course
exercises, double-click on LVB2SOL.exe to extract two
libraries called Bas2Soln.llb and Scope.llb, and a
run-time menu file called Menu.rtm.  

The course images are also available for the Macintosh.  
To obtain a copy of these files, please contact Customer 
Education at (512) 794-0100.
