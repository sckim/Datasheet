This disk accompanies the LabVIEW Basics I Course manual.  Please install the following 
files into the locations indicated:

BASICS1.LLB   This VI library contains subVIs you will use in the course exercises.  Install it into the LabVIEW directory inside the user.lib directory.

LV Basics I   This directory contains VI you will be using throughout the course.  This is also where you will be saving all of your coursework.  Move this directory to the C:\Exercises\ directory.

nidevsim.zip  This zip file contains the LabVIEW instrument driver for the NI Instrument Simulator.  Extract the contents of this file into the LabVIEW directory inside the instr.lib directory.


You will need LabVIEW 6.0 or later to open and use the VIs on this disk.
