제3자가 만든 재사용 문서를 한 벌만 보관하는 곳이다.
부품·용도별 폴더로 나누고, 전량 색인은 `CATALOG.md`에 둔다.
한 문서가 여러 주제에 걸치면 파일을 복사하지 말고 `0_Wiki`에서 링크를 여러 개 건다.

## 넣는 것

- **부품 데이터시트** — `<제조사>_<부품번호>_rev<판>.pdf`
  - 예외: `07_Logic`은 `<부품번호> - <기능>.pdf`로 쓴다. 74·54·4000 계열 번호 앞의 제조사 접두어(SN·DM·MM·MC·CD)는 붙이지 않는다. 한 문서에 여러 부품이 묶이면 `74LS13_14`처럼 `_`로 잇는다 (2026-11-03).
- **장비·계측기·소프트웨어 매뉴얼, 애플리케이션 노트** — `<제조사>_<모델>_<종류>.pdf`
- **부품 3D 모델** — `19_3D_Models\<제조사>_<부품번호>.step` (STEP 우선). 제조사·외부 제공 모델만 넣고, 프로젝트 전용 조립체(케이스·기판 STEP·가공 변형)는 해당 프로젝트에 둔다. 출처·취득일·메모는 `19_3D_Models\README.md` 표에 적는다 (2026-11-11 신설).

옛 `Datasheets\`·`Manuals\` 두 폴더는 2026-09-07에 비우고 지웠다. 그 구분은 이제 `15_Instruments`·`16_Software`·`17_BioMedical`·`18_AppNotes` 같은 분류가 대신한다.

제조사별·연도별 하위 폴더는 만들지 않는다.

## 찾는 법

`CATALOG.md` — 전량 1,957건의 색인이다(분류 폴더 바로 아래 문서 857 + 하위 폴더 묶음 1,100, 2026-11-11 실물 기준). 분류별로 묶고 문서마다 링크를 걸어 두었다. 하위 폴더 묶음은 문서만 개별로 올리고 소스·도구는 확장자별 건수로 적는다.
파일을 넣거나 뺀 뒤에는 `_ops\lib_catalog_rebuild_20261111.py`를 다시 돌려 카탈로그를 고친다(20261103 판에서 19번 분류와 분류 설명 이어받기를 보완한 것이다).

이동 이력은 `_ops\`에 있다 — `lib_regroup_log.csv`(재배치 767) · `lib_cleanup.csv`(점검분 29) · `lib_fds.csv`(아카이브 이관 70) · `lib_dedup.csv`·`lib_dedup2.csv`(중복 격리 30) · `lib_logic_tidy_20261103.csv`(07_Logic 이름 통일·재분류 21).

## 중복 격리

내용이 같은 잉여본은 지우지 않고 `_ops\_dup_6Library\`로 옮겨 둔다. 이름은 `<원래폴더>__<파일명>`이라 되돌릴 수 있다.
판(rev)이 다르거나 제조사가 다르면 중복이 아니다 — 둘 다 둔다. 판정 근거는 `CATALOG.md` 말미에 있다.
